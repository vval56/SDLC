## Описание проекта

Учебное Java-приложение «Сколько раз ты сказал “потом”», разработанное в рамках лабораторных работ. Приложение имеет графический интерфейс на Swing и построено по паттерну MVC с активной моделью.

Пользователь вводит возраст, после чего приложение рассчитывает приблизительное количество случаев прокрастинации за жизнь по формуле:

```text
возраст × 365 дней × 3 раза в день
```

## Функциональные требования

1. На главной форме отображается кнопка «Ввести данные».
2. По нажатию кнопки открывается диалог ввода возраста.
3. При повторном открытии диалога последнее корректное значение восстанавливается.
4. После ввода возраста на главной форме отображаются возраст и рассчитанное количество случаев «потом».
5. Некорректный формат и возраст вне диапазона от 1 до 120 лет сопровождаются сообщением об ошибке.

## Архитектура

Проект построен по паттерну **MVC (Model – View – Controller)** с активной моделью:

- **Model** (`ProcrastinationModel`) хранит возраст и результат расчета, уведомляя подписчиков об изменениях.
- **View** (`MainView`, `InputDialog`) отображает состояние приложения и принимает пользовательский ввод.
- **Controller** (`ProcrastinationController`) обрабатывает действия пользователя, валидирует ввод и изменяет модель.
